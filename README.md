# ember（七日の灯）

ホーム画面の名前は `ember` — 手をかけるのをやめても燃えている残り火のこと。
七日ともし切ったものは、そこへ移る。リポジトリとURLは `nanoka` のまま。

習慣は「1分でできる行動 ＋ すでにある行動へのくっつけ先」の二つで持つ。
7日連続でともし切ると浄化して記録に移る。同時に持てるのは3つまで。

画面は横に三面。色は黒と光のひとつだけ。灯ったものだけが発光する。

**左：書く** — 真ん中に◯がひとつ。押すと二つの欄が開く（1分の行動と、
くっつけ先）。keepで閉じて◯に戻る。三つ埋まっていても書ける（待ちへ）。
くっつけ先の欄には、会社員の一日にすでにあるはずの行動（歯みがきのあと／
席についたあと／布団に入るまえ …32）が、開くたびに一つ、下敷きとして入る。
思い浮かばないときは**下へ引く**と、記録に残る人の習慣が一枚ずつ落ちてくる。
**131人**（作家・作曲家・画家・科学者・数学者・医師・映画監督・振付家・
アスリート・起業家・経営者・投資家・哲学者・建築家・デザイナー・料理人・探検家）。
見た人は端末に覚えておくので、**全員に会うまで同じ人は出てこない**。
引くたびに次が現れる。**読むだけ**。取り込むボタンは置かない。
**上へ払う**と戻る（書きかけがあれば、書きかけへ戻る）。

縦スクロールは使っていない。指の動きを面にそのまま渡して入れ替える。
縦と決まってから指を捕まえるので、横の面送りとは喧嘩しない。
速く払えば短くても決まる（勢いを見る）。

**中央：今日** — 三行あるだけ。ふれると灯る。行ごとに `edit` を置いてあるので、
直すときに灯すを踏まない。誤って灯しても `undo`（9秒）と、
`edit → put today's light out` でいつでも戻せる。

三つが埋まっていても書ける。あふれた分は**待ち**に溜まる。
**上へ払う**と待ちの一覧。空きがあれば `set` でそのまま入る。埋まっていれば
「どれと入れ替える？」と三つが出て、選んだものが待ちの先頭へ下がる（記録はそのまま）。
**下へ引く**と浄めたものの一覧。`bring back` で戻せる（空きがあれば三つへ、
無ければ待ちへ）。今日の面の上下の端に、それぞれの数が出る。
七日ともし切って枠が空くと、待ちの先頭が自動で繰り上がる。

**右：記録** — 日付、灯／浄／連、70日のマス、浄めたもの、持ち運び。
**末尾まで送ってから上へ払う**と **notes**（掲示板）。直したいところを溜める場所で、
書いてもアプリは変わらない。あとでまとめて読み、改修のもとにする。
書き出し（copy out）にも一緒に入る。

待ちに置いたものは `edit` であとから直せる（言葉がずれていても捨てなくていい）。

## 構成

```
index.html      アプリ本体（1ファイル。フレームワークなし）
manifest.json   display:standalone / アイコン / テーマ色
sw.js           ネット優先・キャッシュ退避。圏外でも開ける
icons/          180(apple-touch) / 192 / 512
```

## 公開（GitHub Pages）

```bash
gh repo create nanoka --public --source="/Users/wota/Documents/ChatGPT/AI Engineering/nanoka" --push
```

そのあとリポジトリの Settings → Pages で Source を `main` / `/ (root)` にする。
数分で `https://<account>.github.io/nanoka/` が生きる。

更新は push するだけ。`sw.js` の `CACHE` の値（`nanoka-v1`）を変えると、
古いキャッシュを捨てて確実に新しい版が入る。

## ホーム画面に置く

1. iPhoneのSafariで公開URLを開く
2. 共有ボタン → 「ホーム画面に追加」
3. アイコンから起動。以後は全画面

## 記録の保存先

この端末のブラウザ（localStorage）だけ。サーバーには何も送らない。
端末を移すときは 記録の面 → settings → copy out で文字列を控え、移す先で bring in。
